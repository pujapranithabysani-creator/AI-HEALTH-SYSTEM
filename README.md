# AI Health Prediction System

A smart healthcare analytics dashboard that evaluates patient health based on core biomarkers.

## Features
- Patient Management: Add, view, edit, and delete patient records.
- AI Analysis: Automatically categorizes patient health status based on medical thresholds.

## How to Run
1. **Backend:** Navigate to the `backend` folder, run `pip install -r requirements.txt`, then `python app.py`.
2. **Frontend:** Navigate to the `frontend` folder, run `npm install`, then `npm start`.
